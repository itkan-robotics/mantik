### Java on Mantik

These lessons teach Java from the ground up, with examples that also show up in FTC and FRC projects. You do not need prior programming experience.

<RulesBox title="Why teams use Java">

- FTC robot code is written in Java (OnBot Java or Android Studio).
- FRC teams commonly use Java with WPILib.
- The language is strongly typed and object-oriented, which matches how robot projects are structured.
- The same skills transfer to coursework, internships, and other languages.

</RulesBox>

### Module map

The sidebar groups are meant to be taken in order when you can.

- **Java Basics:** Printing, variables, math, and arrays.
- **Programming Logic:** Conditionals, methods, control flow, and try/catch.
- **Loops and Iteration:** `for` and `while` loops and when to use each.
- **Object-Oriented Programming:** Classes through polymorphism.
- **Data Structures:** Arrays, lists, stacks, queues, trees, and graphs.
- **Common Algorithms:** Search, sort, traversals, recursion, and dynamic programming.
- **Functions as Data:** Lambdas, method references, and functional interfaces.
- **Design Patterns:** Factory methods, dependency injection, and commands.
- **Concurrency and Multithreading:** Threads, races, executors, and thread-safe collections.
- **Version Control with Git & GitHub:** Branches, remotes, and team workflow.

### How to work through a lesson

- Read the explanation, then run or type the examples.
- Do the exercises at the bottom before moving on.
- Use search if you need to revisit one topic.

<RulesBox title="What you need">

- A computer and a browser (for lessons here) or a JDK for local practice.
- Patience to fix small syntax errors; that is normal.

</RulesBox>
