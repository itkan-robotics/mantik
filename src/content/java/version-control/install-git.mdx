### Install Git

Install Git before you clone or create a team repository. Builds differ by operating system; use the installer from the official site or your package manager.

### Checklist

- Run `git --version` to see if Git is already installed
- Download the installer for your OS from [git-scm.com](https://git-scm.com/)
- Accept defaults unless your mentor specifies otherwise
- Run `git --version` again to confirm
- Optional: install [GitHub Desktop](https://desktop.github.com/) if you prefer a GUI

### Configure your identity

Commits record who made them. Set your name and email once per machine:

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --list
```

`--global` applies to all repositories on this computer. Omit it to set identity for one repo only. Use the email tied to your GitHub account if you plan to push there.
