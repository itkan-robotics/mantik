### GitHub Desktop

GitHub Desktop is a graphical client for Git. It runs the same commands as the terminal; the UI shows status, diffs, and history.

### Setup

- Install from [desktop.github.com](https://desktop.github.com/)
- Sign in with your GitHub account
- Set your Git name and email in preferences
- Clone a team repo or create a new one

### Daily use

- **Changes** tab lists modified files
- Check files to stage them
- Write a commit summary and commit
- **Push origin** / **Pull origin** sync with GitHub

### Branches in the app

Create or switch branches from the branch dropdown. Open a pull request from the app when your branch is pushed. Delete merged branches from the branch menu.

<RulesBox title="Robotics team workflow">

Clone the team repo once per machine. Branch for each feature. Commit with messages a mentor can understand. Push and open a PR for review before merging to main.

</RulesBox>

### GUI vs terminal

Desktop covers most day-to-day work. The terminal is still useful for odd merges, scripting, and CI. Many developers use both.
