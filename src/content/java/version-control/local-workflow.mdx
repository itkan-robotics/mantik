### Local workflow

These commands track robot code on your laptop before anything goes to GitHub.

### Three places Git tracks

1. **Working directory** — files you edit normally
2. **Staging area** — changes you selected for the next commit (`git add`)
3. **Repository** — committed snapshots (`.git` folder)

Typical flow: edit files → `git status` → `git add` → `git commit` → `git log`.

### Common commands

```bash
git init          # Create new repository
git clone         # Copy existing repository
git status        # Check file states
git add           # Stage files for commit
git commit        # Save staged changes
git log           # View commit history
git diff          # See changes between commits
```

Start a new folder with `git init`, or `git clone <url>` to copy a team repo. Write a short commit message that says what changed and why.
