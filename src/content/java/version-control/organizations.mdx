### Organizations

A **GitHub Organization** groups repositories and members under one account. FRC and FTC teams often use one org for robot code, docs, and side projects.

### Setup

- Create an org from GitHub account settings
- Choose a name the team can keep across seasons
- Set visibility (private is typical for robot code)
- Invite students and mentors with appropriate roles

### Teams and access

Create teams (programmers, leads, read-only mentors). Grant repo access to teams instead of individuals when you can. Common levels: read, write, admin. Review membership each season.

### GitHub Education

Students can apply for [GitHub Education](https://education.github.com/pack) benefits, including private repos and partner tools. [GitHub Classroom](https://classroom.github.com/) helps teachers assign and collect repos if your program uses it.

### Security

Use private repos for competition code. Require 2FA for org members when possible. Limit admin to leads. Remove access when someone leaves the team.
