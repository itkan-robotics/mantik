### About each section

- **Java Training:** Variables, control flow, classes, data structures, algorithms, concurrency, and Git. Many Java lessons include a **Run** button so you can try code in the browser without installing a JDK.
- **FTC Training:** OnBot Java and Android Studio—hardware, teleop, autonomous, odometry, and debugging.
- **FRC Training:** Command-based programming, vendor hardware, control theory, pose estimation, and tools such as PathPlanner and AdvantageKit.
- **Competitive Training:** Data structures, algorithms, complexity, and contest strategy, with runnable Java examples where they help.

### How to navigate

Pick a training path above, or open **PID Simulation** to practice tuning. Lessons for each section are listed in the sidebar. New to programming: start with Java Training. Already on a team: jump to FTC or FRC.
