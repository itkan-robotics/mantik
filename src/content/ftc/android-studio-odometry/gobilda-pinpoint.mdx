### What is goBILDA Pinpoint?

Pinpoint is goBILDA’s bundled odometry computer: three encoder wheels in a standard layout so teams can skip custom dead-wheel fabrication.

### Hardware Overview and Installation

Follow goBILDA’s mounting guide so wheel alignment matches the device’s expected geometry. Details: [goBILDA Pinpoint product page](https://www.gobilda.com/pinpoint-odometry-computer-imu-sensor-fusion-for-2-wheel-odometry/).

### Integrating Pinpoint with Android Studio

The FTC SDK includes [GoBildaPinpointDriver](https://javadoc.io/doc/org.firstinspires.ftc/Hardware/latest/com/qualcomm/hardware/gobilda/GoBildaPinpointDriver.html) to read the three encoders (and fusion features on supported firmware).

### Sample Initialization and Usage in Android Studio

Basic OpMode readout:



```java
import com.qualcomm.hardware.gobilda.GoBildaPinpointDriver;

GoBildaPinpointDriver pinpoint;

@Override
public void runOpMode() {
    pinpoint = hardwareMap.get(GoBildaPinpointDriver.class, "pinpoint");
    waitForStart();
    while (opModeIsActive()) {
        int leftTicks = pinpoint.getLeftEncoder().getCurrentPosition();
        int rightTicks = pinpoint.getRightEncoder().getCurrentPosition();
        int centerTicks = pinpoint.getCenterEncoder().getCurrentPosition();
        telemetry.addData("Left Encoder", leftTicks);
        telemetry.addData("Right Encoder", rightTicks);
        telemetry.addData("Center Encoder", centerTicks);
        telemetry.update();
    }
}
```

### Best Practices and Maintenance

Keep wheels clean, cables strain-relieved, and mounts tight. Re-check calibration if you change wheel pods or hit hard impacts.

### Comparing Pinpoint to Custom Odometry Solutions

Pinpoint trades cost for faster setup and repeatable hardware. Custom dead wheels fit odd chassis layouts but take design and machine time. Pick based on budget, build season, and how much you want to own the mechanical design.
