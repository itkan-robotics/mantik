### Before you start

New to telemetry? Read [Telemetry Logging](../environment-setup/telemetry-logging.json) first.

### Why organize telemetry?

Drivers scan the Driver Station under time pressure. Section headers, formatted numbers, and warnings reduce mistakes during matches and tuning.

### Grouping and formatting

Use `addLine()` for sections and `"%.2f"` for decimals.

### Grouped telemetry example

```java
telemetry.addLine("=== Drive ===");
telemetry.addData("L", "%.2f", leftDrive.getPower());
telemetry.addData("R", "%.2f", rightDrive.getPower());
telemetry.addLine("=== Arm ===");
telemetry.addData("Position", armMotor.getCurrentPosition());
telemetry.addData("Limit", armAtLimit ? "YES" : "NO");
telemetry.update();
```

### Persistent messages

`telemetry.log()` keeps warnings and events on screen longer than a single `addData` line.

### Event logging example

```java
if (Math.abs(leftDrive.getPower()) > 0.9) {
    telemetry.log().add("Warning: High left drive power!");
}
if (armAtLimit) {
    telemetry.log().add("Arm at limit!");
}
telemetry.update();
```

### Warnings and mode indicators

Use `if` checks to flag slow mode, limits, or disconnected sensors.

### Warnings example

```java
if (slowMode) {
    telemetry.addData("Mode", "SLOW");
}
if (armMotor.getCurrentPosition() > ARM_UPPER_LIMIT) {
    telemetry.addData("Warning", "Arm at upper limit!");
}
if (!sensor.isConnected()) {
    telemetry.addData("Error", "Sensor disconnected!");
}
telemetry.update();
```

### Telemetry for tuning

Show target, measured value, error, and output while tuning PID. See [PID Control](../advanced-movement-control/pid-control.json).

### PID telemetry example

```java
telemetry.addData("Target", targetPosition);
telemetry.addData("Current", armMotor.getCurrentPosition());
telemetry.addData("Error", targetPosition - armMotor.getCurrentPosition());
telemetry.addData("Output", pidOutput);
telemetry.update();
```

<RulesBox title="Best Practices for Advanced Telemetry" subtitle="Keep the screen useful">

- Call `telemetry.update()` once per loop.
- Use clear, descriptive labels and group related data.
- Limit the amount of data to avoid clutter.
- Use `telemetry.log()` for persistent or event-based messages.
- Display warnings and errors for critical issues.
- Use telemetry to help with tuning and debugging.

</RulesBox>
