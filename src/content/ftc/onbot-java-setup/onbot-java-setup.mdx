### What is OnBot Java?

OnBot Java is a browser-based editor on the Control Hub. You write and run FTC Java without installing Android Studio on a laptop.

### Before You Write Robot Code

Work through the topics below before driving motors. They cover the FTC SDK, OpMode structure, telemetry, and the Control Hub and Expansion Hub.

Suggested order: **FTC SDK Basics**, **OpMode Structure**, **Linear vs Iterative OpModes**, **Telemetry Logging**, then **Control Hub & Expansion Hub**.
