### Why Advanced Movement Control?

Open-loop motor power is enough for teleop, but auto needs repeatable distance, angle, and mechanism position. Feedback control closes the loop with sensors so the robot corrects error instead of hoping timing and battery voltage stay the same.

### What You'll Learn in This Unit

- Why feedback matters for drivetrains and mechanisms.
- PID controllers in Java for position and heading.
- Applying PID to drivetrain, IMU turns, and arms.
- Motion profiles for smooth acceleration and deceleration.
- Combining PID with feedforward on real mechanisms.

### Learning Path

1. **External Libraries** — optional frameworks that bundle control and structure.
2. **PID Control** — P, I, D terms, a basic loop, and tuning.
3. **Robot PID Control** — drivetrain, multi-axis, and mechanism examples.
4. **Motion Profiling** — trapezoidal profiles and pairing with PID.

### Recommended Prerequisites

- Comfortable Java and basic classes.
- FTC SDK project open in Android Studio.
- Motors configured with encoders; basic teleop experience.
