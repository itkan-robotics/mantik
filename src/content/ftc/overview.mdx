### FTC Programming

These lessons teach FTC robot programming in two environments: OnBot Java (browser editor on the Control Hub) and Android Studio (local IDE and Gradle builds). Start with OnBot Java if you are new; move to Android Studio when you need larger projects, libraries, and advanced control.

<RulesBox title="Important Disclaimer" subtitle="Official Documentation">

- This curriculum is a learning guide, not a substitute for official FTC documentation
- For rules, hardware specs, and SDK APIs, use [FIRST Tech Challenge](https://www.firstinspires.org/robotics/ftc) and [FTC Docs](https://ftc-docs.firstinspires.org/)
- When documentation and these lessons disagree, trust the official sources

</RulesBox>

### Modules

**OnBot Java — Setup** — Control Hub and Expansion Hub, SDK layout, OpMode types, telemetry

**OnBot Java — Robot hardware** — DC motors, servos, sensors

**OnBot Java — TeleOp** — Gamepad mapping, drivebases, telemetry for drivers

**OnBot Java — Autonomous** — Time-based and encoder-based moves

**OnBot Java — Debugging** — Basic debugging, state machines, code organization, common failures

**Android Studio — Setup** — IDE, project layout, Git workflow

**Android Studio — Advanced movement** — PID, motion profiling, external libraries

**Android Studio — Odometry** — Dead-wheel encoders, three-wheel odometry, goBILDA Pinpoint

**Android Studio — Path planning** — Pose and path theory, custom following, library comparison

**Android Studio — Debugging and practices** — Android Studio debugger, loop performance, team workflow, code review, unit tests, FTCDashboard

<RulesBox title="Prerequisites" subtitle="Helpful before you start">

- Basic Java (variables, methods, classes)
- Familiarity with your team’s robot hardware, or a practice chassis
- Patience for trial-and-error; robot software rarely works on the first run

</RulesBox>

### Where to start

New to FTC code: **OnBot Java Setup**, then **FTC SDK Basics**. Already using Android Studio: **Android Studio Setup**, then the movement or debugging track that matches your season goals.
