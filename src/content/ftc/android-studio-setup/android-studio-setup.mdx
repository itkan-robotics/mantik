### What is Android Studio for FTC?

Android Studio is Google’s official IDE for Android apps. FTC teams use it to write, test, and deploy robot code in Java on a computer, with version control, refactoring, and debugging tools that OnBot Java does not provide. This learning path suits teams working on odometry, path planning, advanced control, or computer vision.

Learn more: [FTC Docs: Android Studio Programming Tutorial](https://ftc-docs.firstinspires.org/en/latest/programming_resources/android_studio_java/Android-Studio-Tutorial.html)

### Why Use Android Studio for FTC?

Code completion, refactoring, Git integration, and step-through debugging help you keep a large codebase maintainable. You need some Java comfort to get started, but the payoff is more control than Blocks or OnBot Java.

### System Requirements

Use a recent CPU, at least 8 GB of RAM (16 GB is better), and several gigabytes of free disk space. Check the [Android Studio site](https://developer.android.com/studio) for current requirements.

### Installing Android Studio

1. Download the installer from the [Android Studio website](https://developer.android.com/studio).

2. Run the installer and follow the setup wizard.

3. During installation, select the default options unless your team has specific requirements.

4. After installation, launch Android Studio to complete the initial setup.

5. For a more detailed guide, see [FTC Docs: Android Studio Programming Tutorial](https://ftc-docs.firstinspires.org/en/latest/programming_resources/android_studio_java/install/install.html).

### What is the Android SDK?

The Android SDK supplies the libraries and tools Android Studio uses to build and run apps, including the Robot Controller project. Without it, your code will not compile or deploy.

Learn more: [Android Studio Official Site](https://developer.android.com/studio)

### Why Do FTC Teams Need the SDK?

FTC robots run Android, so your project must target a compatible SDK API level. When you deploy from Android Studio, you install an updated Robot Controller build on the Control Hub. Many teams plug the Driver Station phone into the computer over USB so the wireless link to the Control Hub stays stable while you download.

### Installing the SDK via Android Studio

The first-run wizard installs the SDK if you accept the defaults. You can add or change SDK versions later in **Tools → SDK Manager**. Match the API level FTC Docs recommend for your season (often API 25 or newer).

### Managing SDK Tools and Updates

You can install extra SDK tools from the same manager. Avoid random SDK upgrades mid-season unless FTC Docs say they are safe for your SDK version.

For more information, see [Android Studio: Update the IDE and SDK Tools](https://developer.android.com/studio/intro/update).

### Downloading and Setting Up the FTC SDK Project

Download or clone the [FTC SDK repository](https://github.com/FIRST-Tech-Challenge/FtcRobotController), then in Android Studio choose **Open** and select that folder.

### High-Level Project Layout

The repo splits your team code from the official SDK so you can pull SDK updates without merging through your OpModes.

For a visual overview, see [FTC Docs: Android Studio Programming Tutorial](https://ftc-docs.firstinspires.org/en/latest/programming_resources/android_studio_java/Android-Studio-Tutorial.html).

### Key Files and Directories

- **FtcRobotController**: Contains the official SDK code. Do not modify files here.

- **TeamCode**: This is where you write your own OpModes and custom classes.

- **build.gradle**: The build configuration file for each module.

- **AndroidManifest.xml**: Declares app permissions and components.

- **libs/**: Place any third-party libraries here if needed.

### Where to Write Your Code (TeamCode vs. FtcRobotController)

Put OpModes and team classes in **TeamCode**, not in **FtcRobotController**. New OpModes live under **TeamCode/src/main/java/org/firstinspires/ftc/teamcode**.

### Gradle and Build System Basics

Gradle compiles the project, resolves dependencies, and packages the Robot Controller APK. You rarely edit `build.gradle` files as a beginner, but build errors often point there.

Learn more: [Gradle User Guide](https://docs.gradle.org/current/userguide/userguide.html)
