### Template Project

Use the **Timed Robot** WPILib template so `Robot.java` already defines the lifecycle methods.

### Overview

Configure one intake motor in `Robot.java` and run it forward on A, reverse on B, and stop when neither is pressed.

<RulesBox title="Requirements" subtitle="The intake must:">

- Run forward (collect) on 'A' press.
- Run reverse (eject) on 'B' press.
- Stop when no button is pressed.
- Be configured (Coast mode, Current Limit).

</RulesBox>

### Step 1: Imports and Class Setup

Add imports for `TimedRobot`, the gamepad, and your motor vendor classes. The template already declares `public class Robot extends TimedRobot`.

```java
package frc.robot;

import edu.wpi.first.wpilibj.TimedRobot;
import edu.wpi.first.wpilibj.XboxController;
import com.ctre.phoenix6.hardware.TalonFX;
import com.ctre.phoenix6.configs.TalonFXConfiguration;
import com.ctre.phoenix6.signals.InvertedValue;
import com.ctre.phoenix6.signals.NeutralModeValue;
import com.ctre.phoenix6.controls.DutyCycleOut;

public class Robot extends TimedRobot {
    // The template provides all lifecycle methods
    // We'll add fields here next
}
```

### Step 2: Declare Hardware

Declare the controller on USB port 1 and the intake motor on CAN ID 5.

```java
public class Robot extends TimedRobot {
    // Controller on USB port 1
    private XboxController m_controller = new XboxController(1);
    // Intake motor on CAN ID 5
    private TalonFX m_motor = new TalonFX(5);
    private DutyCycleOut m_out = new DutyCycleOut(0);
}
```

### Step 3: Configure Motor in robotInit()

In `robotInit()`, set inversion, Coast idle mode (free spin at zero output), and a 30 A current limit.

### Understanding the Control Logic

Only one branch runs at a time. Forward uses 60% output; reverse uses 40%. Tune both on your mechanism.

### Power Values

0.6 and -0.4 are starting points—adjust after testing on the real intake.

### Troubleshooting

**Wrong Direction:** Change inversion setting in `robotInit()`.

**No Movement:** Check CAN IDs and power values.

**Motor Drifts:** Ensure the `else \{ stop \}` block exists to stop the motor when no button is pressed.
