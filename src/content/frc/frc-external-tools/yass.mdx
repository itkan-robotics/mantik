### What is YASS?

YASS (Yet Another Software Suite) bundles libraries for swerve, mechanisms, and vision so teams can adopt common patterns without writing everything from scratch.

The suite includes:

**YAGSL** ([Yet Another General Swerve Library](https://yagsl.gitbook.io/yagsl/))

**YAMS** ([Yet Another Mechanism System](https://yetanothersoftwaresuite.com/))

**YAMG** ([Yet Another Mechanism Generator](https://www.yamgen.com/))

**YALL** (Yet Another Limelight Library)



Learn more: [YASS Official Website](https://yetanothersoftwaresuite.com/)

### YAGSL: Swerve Made Easy

YAGSL is a swerve library with JSON configuration for motors, encoders, and gyros.

**Key Features:**

- [JSON-based configuration](https://yagsl.gitbook.io/yagsl/) (change motors/offsets without recompiling).

- [Built-in odometry and pose estimation](https://yagsl.gitbook.io/yagsl/).

- [Simulation support](https://yagsl.gitbook.io/yagsl/) out of the box.

- Support for various vendors (CTRE, REV, Thrifty, NavX).



Learn more: [YAGSL Documentation](https://yagsl.gitbook.io/yagsl/) | [YAGSL Example Project](https://github.com/BroncBotz3481/YAGSL-Example)

### YAMG: Mechanism Generator

YAMG is a web tool that generates command-based Java for elevators, arms, pivots, and similar mechanisms from motor type, gearing, and limits.

**Features:**

- [Visual configuration interface](https://www.yamgen.com/).

- Generates command-based subsystems.

- Includes simulation support.

- Supports YAMS library integration.



Try it: [YAMG Website](https://www.yamgen.com/)

### YAMS: Mechanism System

YAMS standardizes mechanism control and sensor reads so the same subsystem code can target hardware or simulation with small changes (often a `.simIterate()` call in sim).

[YAMS documentation](https://yetanothersoftwaresuite.com/) | [API](https://yetanothersoftwaresuite.com/)

<RulesBox title="YASS Best Practices" subtitle="Getting the most out of the suite:">

- Use the [JSON configuration for YAGSL](https://yagsl.gitbook.io/yagsl/) to keep hardware details out of code.
- Leverage [YAMG](https://www.yamgen.com/) to generate the boilerplate code for your arms and elevators.
- Test in simulation! YASS libraries are built with simulation priority.
- Join the [YAGSL/YASS community](https://github.com/BroncBotz3481/YAGSL-Example) for support and updates.

</RulesBox>
